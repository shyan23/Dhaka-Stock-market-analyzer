# 🚀 Quick Start Guide - Stock Market Analyzer

**Get up and running in 5 minutes!**

---

## 📦 One-Time Setup

### Step 1: Install Docker Desktop
1. Download: https://www.docker.com/products/docker-desktop
2. Install and restart your computer
3. Start Docker Desktop (look for whale icon in system tray)

### Step 2: Download & Extract Project
1. Download the project ZIP file
2. Extract to your Desktop
3. Open the `stock_market_analyzer` folder

---

## ▶️ Running the Application

### Method 1: Double-Click (Easiest)
1. **Double-click** `deploy-windows.bat`
2. Wait for setup to complete
3. Application will open in your browser automatically!

### Method 2: PowerShell (Recommended)
1. **Right-click** in project folder → "Open in Terminal"
2. Type: `.\deploy-windows.ps1 start`
3. Open: http://localhost:8501

---

## 🎯 Daily Use

| Action | Command |
|--------|---------|
| **Start** | Double-click `deploy-windows.bat` |
| **Stop** | `.\deploy-windows.ps1 stop` |
| **Status** | `.\deploy-windows.ps1 -Status` |
| **Logs** | `.\deploy-windows.ps1 -Logs` |

---

## 🌐 Access Your App

Once started, go to: **http://localhost:8501**

---

## 🆘 Need Help?

1. **Won't start?** → Make sure Docker Desktop is running
2. **Browser won't load?** → Wait 2 minutes, then refresh
3. **Still stuck?** → Run `.\deploy-windows.ps1 -Logs` and share the output

---
